Что изменено и почему

  • Окно занимает весь безопасный экран. Сейчас это тёмный прямоугольник на 55% экрана: слева две подписи «Оружие» и «Улучшения» над пустотой, справа 26 строк текстом примерно 7 dp. Такой текст на 6" не прочитать.
  • Иконки 52 и 48 dp с рамкой и ромбиками тира (цвета из tierColors), стаки в углу. Касание по предмету открывает снизу карточку на пергаменте: описание, урон, перезарядка и сколько убийств набрало это оружие.
  • Характеристики разбиты на группы «Выживаемость / Атака / Урон по типам / Экономика». Нулевые значения («—») по умолчанию скрыты. Сейчас из 26 строк в начале забега 20 — прочерки, и нужное в них теряется. Полный список открывается по «Показать все».
  • Урон по типам — плитки 4×2 с цветом типа, а не семь строк. Пустые типы приглушены, и сразу видно, в какой тип вкладывается билд.
  • Вкладки «Покупки» (история) и «Урон» (статистика за забег). История уходит с боевого экрана, статистику урона можно смотреть во время забега, а не только после смерти.
  • Положительные значения зелёные, все числа набраны Oswald 13–14 sp, подписи Kelly Slab 12,5 sp. Это минимум для чтения с расстояния вытянутой руки.
  • Крестик 48 dp в шапке, рядом пометка «пауза» (окно останавливает время). Колонка характеристик прокручивается, низ затухает — так видно, что ниже есть ещё.

Решить владельцу

  • Прятать ли нулевые характеристики по умолчанию. Опытным игрокам иногда важно видеть «Шанс охоты: —».
  • Числа в карточке предмета (урон, перезарядка) требуют вывода данных из ScriptableObject — это отдельная задача.
  • Тот же макет подходит для просмотра чужого билда из таблицы рекордов (BuildViewerUI): вместо вкладок там будут ник и время.
