Идея

  • Инвентарь — сортируемая таблица: предмет, стак, убийства, урон, доля урона. Сортировка по урону сразу отвечает на главный вопрос жанра: что тащит билд и что можно не качать.
  • Строки 52 dp — удобно листать пальцем. Тир — светящаяся грань плитки и подпись цветом тира.
  • Справа сводка башни моноширинными числами. Бонус урона по типам — столбики (все 7 типов в одном взгляде, нулевые — серые черточки).
  • Статистика урона (сейчас доступна только после смерти) встроена прямо в инвентарь и доступна во время забега.

Решить владельцу

  • Таблица удобна опытным, но новичку суховата. Можно сделать её режимом «Подробно» рядом с сеткой иконок из A.
  • Для колонок «Убийств» и «Урон» во время забега нужно, чтобы DamageStatsManager отдавал данные в реальном времени (сейчас они собираются для экрана после смерти).
