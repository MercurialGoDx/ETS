Идея

  • Итоги — хроника забега: график здоровья башни (красный) и урона в секунду (бирюзовый) по времени, вертикали боссов, иконки покупок в моменты покупки. Видно, где «просело» и после какой покупки билд «включился».
  • Слева — время 50 sp моноширинным шрифтом, рекорд с разницей, счётчики и место в мире. Внизу — топ-3 урона долями.
  • «Заново» — главная кнопка, «В меню» — прозрачная.

Решить владельцу

  • Для графика нужна запись забега: здоровье, урон/с и покупки каждые 1–2 с. Эта же запись — основа «призрака» для режима 1 на 1, поэтому одна работа закрывает две задачи.
  • График сложнее для новичка, чем медали из B. Можно совместить: медали сверху, хроника по кнопке.
