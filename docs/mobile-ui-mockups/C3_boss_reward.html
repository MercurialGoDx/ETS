Идея

  • Награда — «трофейные плиты» со сравнением «было → стало» по каждому затронутому параметру, включая расчётный DPS. Решение принимается по цифрам, а не по названию.
  • Подтверждение удержанием: кнопка заполняется за 0,6 с. Случайное касание при появлении окна ничего не выберет, и отдельный шаг «Забрать» не нужен.
  • Редкость — цветная верхняя грань и подсвеченная иконка. Строгая подача без ленты и лучей: акцент на чтении.

Решить владельцу

  • Удержание вместо второго касания: быстрее, но непривычно. Нужна подсказка при первом боссе.
  • Расчётный DPS требует симуляции или упрощённой формулы. Можно показывать только прямые параметры.
